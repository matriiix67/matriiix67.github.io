朝读夕拾隐私政策

更新日期：2026 年 11 月 15 日

朝读夕拾（DawnRead）用于阅读 EPUB 电子书、查询词典、记录阅读进度和复习单词。本政策说明应用处理的数据、处理目的、保存位置以及你的控制方式。

朝读夕拾由个人开发者黄建莉开发和运营，黄建莉是本政策所述个人信息的处理者（数据控制者）。

首次启动应用时，我们会展示本政策的摘要并征求你的同意；政策发生实质变更时会再次征求同意。

处理的数据

  • 你导入的 EPUB 文件、书籍信息和本地文件路径。
  • 阅读进度、阅读时长、书签、笔记、单词学习和复习记录。
  • 主题、字体、查词方式、提醒开关等应用设置。
  • App Store 提供的购买状态和订阅有效期。
  • 用户主动选择进行 AI 翻译、AI 总结或云端朗读的文本。
  • 用户自行填写的服务商、模型和 HTTPS 接口地址；API Key 保存在系统钥匙串中。

本地保存

书籍、阅读数据和大部分设置默认保存在设备内。删除对应内容或卸载应用会清除设备内相关数据。

例外：AI 翻译与云端朗读的 API Key 保存在系统钥匙串中，仅存于本机、不会通过 iCloud 同步。按照 iOS 的机制，卸载应用后钥匙串中的数据可能仍保留在设备上。如需彻底删除，请在卸载前前往“我的 → 隐私与数据”点击“清除 AI 与语音凭据”。

iCloud 同步

付费用户可主动开启 iCloud 同步。开启后，阅读数据、应用设置（含所选服务商、模型与接口地址，不含 API Key）和选择上传的书籍文件会保存在用户 Apple 账户对应的 CloudKit 私有数据库，用于用户自己的设备间同步。关闭同步会停止后续上传；用户可通过 Apple 提供的 iCloud 存储管理功能删除云端 App 数据。

AI 翻译与云端朗读

付费用户可自行配置 MiniMax、DeepSeek、智谱 GLM（Z.ai）、Kimi 或自定义 HTTPS 服务。用户首次使用 AI 翻译、AI 总结或云端朗读时，应用会说明数据用途和目标服务域名，并在用户允许后发送本次选中的文本。授权按功能与服务域名分别保存，服务域名变化时会再次请求授权。

云端服务会按照服务提供方的隐私政策处理所发送的文本。使用自定义服务时，用户负责确认服务方的数据处理地点、保存期限与合规条件。应用仅发送完成本次请求所需的选中文本，不会自动上传整本书。

第三方 AI 服务提供方

应用为以下服务商预置了国际版开放平台接口。只有在你填写对应 API Key 并同意数据处理提示后，选中的文本才会发送给所选服务商：

  • MiniMax：Nanonoble Pte. Ltd.（新加坡），接口 api.minimax.io（条款与隐私政策）
  • DeepSeek：杭州深度求索人工智能基础技术研究有限公司（中国），接口 api.deepseek.com（隐私政策）
  • 智谱 GLM（Z.ai）：JINGSHENG HENGXING TECHNOLOGY PTE. LTD.（新加坡），接口 api.z.ai（隐私政策）
  • Kimi：MOONSHOT AI PTE. LTD.（新加坡），接口 api.moonshot.ai（隐私政策）

你也可以把接口地址改为服务商的其他区域或其他服务，此时文本会发送到你填写的地址。第三方服务可能按其隐私政策留存请求内容，并可通过你提供的 API Key 将请求关联到你在该服务商的账号。

数据存储位置与跨境传输

开发者不运营接收你数据的服务器，应用不会把你的个人信息发送给开发者。数据只会在以下情况离开你的设备：

  • 开启 iCloud 同步后，数据由 Apple 依据 iCloud 条款存储和处理。
  • 使用 AI 翻译、AI 总结或云端朗读时，选中的文本会发送到你所选服务商的服务器，服务器可能位于你所在国家或地区之外（例如新加坡、中国，或你自定义的服务器所在地）。应用会在首次发送前显示目标域名并征得你的同意，是否使用由你自行决定。
  • 购买由 Apple 处理，开发者只能获得 App Store 提供的购买状态和订阅有效期。

数据用途和共享

应用仅为阅读、翻译、朗读、同步、购买和用户支持处理上述数据。处理依据是：提供你所请求的应用功能所必需，以及你对云端 AI 处理的明确同意。应用未集成广告 SDK，未进行跨 App 跟踪，也未出售或共享个人信息用于广告。

保存期限和删除

  • 本地数据保存至用户主动删除相关内容或卸载应用。
  • 钥匙串中的 API Key 保存至用户在“我的 → 隐私与数据”清除凭据；仅卸载应用可能不会删除。
  • iCloud 数据保存至用户通过应用或 Apple 的 iCloud 存储管理功能删除。
  • 云端处理授权记录保存至用户在“我的 → 隐私与数据”撤销授权或卸载应用。
  • 第三方云端服务中的数据保存期限由对应服务方的隐私政策确定。
  • 隐私与支持邮件保存至问题处理完成及履行必要法律义务所需的期限。

隐私选择

用户可以在应用的设置中关闭 iCloud 同步，在“隐私与数据”中撤销全部云端处理授权、清除 AI 与语音凭据，并在阅读、书签、笔记和单词复习页面管理对应数据。完整清除设备数据，请先在“隐私与数据”中清除 AI 与语音凭据，再卸载应用。

你的权利

依据你所在地区适用的数据保护法律（例如欧盟和英国的《通用数据保护条例》），你可能享有查阅、更正、删除、限制或反对处理、数据可携带以及随时撤回同意等权利。撤回同意不影响撤回前处理的合法性。由于上述数据保存在你的设备或你自己的 iCloud 中，你可以直接在应用内查看、导出笔记和删除数据。如需协助，可通过下方联系方式联系我们；你也有权向所在地的数据保护监管机构投诉。
