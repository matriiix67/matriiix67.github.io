回報問題時，建議附上裝置型號、iOS 版本、App 版本、操作步驟和螢幕截圖。

回復購買

進入「我的」，點按訂閱卡片上的「升級」，在購買頁面點按「回復購買」。

iCloud 同步

請確認裝置已登入 iCloud、目前方案包含同步權益（Pro），並在「我的 → 同步」中開啟 iCloud 同步。

朗讀

App 預設使用裝置的系統語音。付費使用者可以在「我的 → 雲端朗讀」中填寫 API 金鑰、模型、HTTPS 端點和音色。首次傳送文字前會顯示資料處理提示。

AI 翻譯

付費使用者可以在「我的 → AI 翻譯」中選擇 MiniMax、DeepSeek、智譜 GLM（Z.ai）、Kimi，或設定自訂的 HTTPS 服務。預設的是各服務商國際版開放平台的端點；API 金鑰與平台區域綁定，如果你的金鑰來自中國大陸平台，請把端點改為對應的大陸端點。請確認 API 金鑰、模型和端點都已填寫。首次傳送選取的文字前會顯示資料處理提示，授權可在「我的 → 隱私與資料」中撤銷。

介面語言

介面支援繁體中文、簡體中文和英文，預設跟隨系統語言；也可以在 iPhone 的「設定 → 朝讀夕拾 → 語言」中單獨切換。AI 翻譯與摘要的輸出語言會跟隨所選語言。
