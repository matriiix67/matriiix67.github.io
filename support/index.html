恢复购买

进入“设置 → 升级 Pro”，点击“恢复购买”。

iCloud 同步

确认设备已登录 iCloud、当前方案包含同步权益，并在设置中开启 iCloud 同步。

朗读

应用默认使用设备系统语音。付费用户可在“我的 → 云端朗读”中填写 API Key、模型、HTTPS 接口地址和音色。首次发送文本前会显示数据处理提示。

AI 翻译

付费用户可在“我的 → AI 翻译”中选择国内服务商或配置自定义 HTTPS 服务。请确认 API Key、模型和接口地址填写完整。首次发送选中文本前会显示数据处理提示，授权可在“我的 → 隐私与数据”中撤销。
