反馈时建议附上设备型号、iOS 版本、App 版本、问题步骤和截图。

恢复购买

进入“我的”，点击订阅卡片上的“升级”，在购买页点击“恢复购买”。

iCloud 同步

确认设备已登录 iCloud、当前方案包含同步权益（Pro），并在“我的 → 同步”中开启 iCloud 同步。

朗读

应用默认使用设备系统语音。付费用户可在“我的 → 云端朗读”中填写 API Key、模型、HTTPS 接口地址和音色。首次发送文本前会显示数据处理提示。

AI 翻译

付费用户可在“我的 → AI 翻译”中选择 MiniMax、DeepSeek、智谱 GLM（Z.ai）、Kimi，或配置自定义 HTTPS 服务。预置的是各服务商国际版开放平台的接口；API Key 与平台区域绑定，如果你的 Key 来自中国大陆平台，请把接口地址改为对应的大陆接口。请确认 API Key、模型和接口地址填写完整。首次发送选中文本前会显示数据处理提示，授权可在“我的 → 隐私与数据”中撤销。

界面语言

界面支持简体中文、繁体中文和英文，默认跟随系统语言；也可以在 iPhone 的“设置 → 朝读夕拾 → 语言”中单独切换。AI 翻译与总结的输出语言跟随所选语言。
